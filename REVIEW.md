## Examined and decided not to be defects

- 'load_dotenv()' before the client is created. Real environment variables take priority by default, which matches the contract.
- 'MongoClient(...)' at import time. PyMongo connects lazily, so importing the module doesn't need a live database. The real problem is that '/health' doesn't check the connection (row 25).
- 'create_employee' pops '_id' before returning. This is correct. The defect is the datetime format (row 6).
- 'list_employees' projection '{"_id": 0}'. This is correct and keeps '_id' out of responses.
- 'compute_late_minutes' for punch-ins inside the window. The sign and floor logic is right once the grace check is fixed. The defects are rows 15 and 16.
- 'compute_work_hours' direction. 'punch_out - punch_in' is the correct order.
- String comparison of 'date' in 'list_attendance'. Valid for 'YYYY-MM-DD' values, once the format is validated (row 22).
- '.env' in the submission. '.env' is only loaded if it exists. It is listed in '.gitignore' and not committed.
